# 📊 Emission Analysis Project

## 📌 Overview

This project analyzes supply chain greenhouse gas emissions using Python.

## 🛠 Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## 📈 Features

* Data Cleaning
* Top 10 Emission Industries
* Distribution Analysis
* Outlier Detection
* Visualization (Bar, Histogram, Boxplot, Pie Chart)

## 🚀 How to Run

1. Download dataset
2. Run `emission_analysis.py`

## 📊 Output

Graphs showing emission patterns and insights
